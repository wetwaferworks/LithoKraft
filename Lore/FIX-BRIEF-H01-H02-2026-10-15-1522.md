## H-01 PickBlock mints free blocks (HIGH)
- File: `game/LithoKraft/src/game/game.cpp` ~1673-1688
- Gate is `st.hit`, not `st.inReach`, and not cheat-gated.
- When no hotbar stack already places the hit block, calls `inventory.addItem(hitBlock, 1)`.
- Effect: any visible block (any distance) can be collected from nothing. Unlimited free items.

Suggested fix:
1. In survival, PickBlock only selects an existing stack (hotbar or main inventory). Do not `addItem`.
2. Put the `addItem` path behind creative / cheat authority only.
3. Require `st.inReach` for any pickup-from-world path.

## H-02 Silica seed never consumed (HIGH)
- Files: `game/LithoKraft/src/content/item_use.cpp` ~32-35; `game.cpp` ~1652 (`kCmdItemUse`)
- Handler plants via `silicaDoPlant` and returns `Handled`, but nothing decrements the seed stack.
- Game thread sends `kCmdItemUse` with no consume; sim handler cannot touch inventory.
- Harvest still drops seeds, so one seed plants forever (infinite / net-positive farm).

Suggested fix:
1. Return a consume count in `ItemUseResult` (or a sim→game receipt event).
2. Decrement the used stack only on `Handled`, matching place-consumption.
3. Keep Failed paths non-consuming.
