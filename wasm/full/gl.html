LITHOKRAFT — FULL TEST

The full engine + game in WebAssembly, booting the GL33 renderer on WebGL2 (shaders: the pack carries GLSL ES 3.00 translations; chunk meshes run with --gl-arena off because WebGL2 has no base-vertex draw — same meshes and pixels, per-mesh VAOs instead of one arena) — and it is playable: click the game, press Enter on the launch menu (Play), then click again to grab the mouse (Esc releases). WASD moves, Space jumps, F3 toggles the live tick overlay. Same build, same world seed as the software page. Add ?bench=1 to the URL for the original 4-second bench boot, ?debuginput=1 to echo every input event into the log below. Pacing switches: ?radius=N (chunk stream radius, default 16) and ?aa=on / ?aa=4 (multisampled framebuffer, default off) — combine freely, e.g. gl.html?radius=16&aa=on. On touch devices, basic on-screen controls (move stick, look-drag, buttons) appear automatically — force with ?touch=1, hide with ?touch=0. Play does not start by itself: the launch menu waits for Enter / a click on Play — on touch devices, the ENTER button at the top right. The Copy log button under the log copies the whole log for pasting.
