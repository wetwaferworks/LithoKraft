# game

`LithoKraft/` is the LithoKraft game: gameplay sources (`src/`), the game pack (`assets/`), scripts and config. It is built by the engine's CMake project (`engine/`). See `LithoKraft/README.md` for gameplay and controls.

Note: `LithoKraft/assets/art_incoming/` keeps its dated batch folder names because they are part of the shipped asset tree.
