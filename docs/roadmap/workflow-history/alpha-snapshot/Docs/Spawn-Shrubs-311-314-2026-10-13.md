sizeCells 12 — with only `seed` set), via a standalone verifier linked against
the production engine libraries:

| measure | seed 311 | seed 314 |
|---|---|---|
| filled pixels (16×16) | 156 | 156 |
| alpha-mask differing pixels between the two | **0** (one shared mask) | |
| filled pixels whose RGB differs between the two | 152 / 156 | |
| distinct RGB colours | 128 | 134 |
| pixels differing from the reference PNGs | **0 / 256** | **0 / 256** |

The engine output is byte-identical to the reference renders at every pixel —
the Python replication the references came from was exact, and the shipped
assets below are the in-engine bytes regardless (regenerated through the
engine path, never hand-copied). The pair obeys the shrubs.h law: *the seed
paints only the colour speckle, never the alpha mask.*

are deliberately **not** members of the engine's canonical formula family
(that set is seed-invariant by design, and `formulaTextureIndexFor`

`textures/ui/icons/<name>.png` in pack_32/64 (10 new PNGs). All 35 pre-existing
plant PNGs were md5-checked across the regeneration: **zero drift**.

Registration followed the house path — manifest entries appended (with real

## 4. Placement — `waferSetup`, deterministic, fail-closed

Placement lives in `game/LithoKraft/src/game/dimensions.cpp: waferSetup`,
immediately after `buildDemoCircuit` returns the spawn (the same setup-stamp
contract the demo circuit itself uses — stamped into the generated columns at
`Dimension::load`, then overlaid by the save on later loads, so the pair
persists, evicts and reloads like any other placed block):

- **311 at (spawn.x − 3, platform top + 1, spawn.z)** — three cells west
- **314 at (spawn.x + 3, platform top + 1, spawn.z)** — three cells east

For the standard world (size ≥ 6 chunks) that is **(55, 266, 42)** and
**(61, 266, 42)**, spawn at (58, 266, 42) — verified live by the capture tool
(§5): `west=65, east=66, spawn cell=0 (air)`.

Determinism: the Wafer generator is seed-pinned to 0 and the spawn is a pure
function of world size, so the cells are a pure function of the world — no
per-load randomness anywhere in the path. Fail-closed planting rule: a shrub
is set only where the surface cell is solid and the cell above is air; an
occupied cell is left exactly as found (never overwritten). The spawn cell
itself is never touched.
