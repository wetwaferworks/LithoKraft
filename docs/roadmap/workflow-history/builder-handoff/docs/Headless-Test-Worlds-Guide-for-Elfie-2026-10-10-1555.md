# Headless Test Worlds: Setup Guide for Elfie (CONFIDENTIAL)
From Cortana for JD. For JIT compilation work.

## Key fact: the test worlds are code, not save files
Every profiling world is generated by a scene builder in LithoKraft when you pass `--bench-scene <name>`. There are no world files to ship, because they're in the source you already have (branch elfie/2026-10-10, commit f4b09f5 and later). Same seed, same scene, every run. That makes them deterministic and ideal for JIT correctness checks.

## Scenes
| Scene | What it stresses | Size flags |
|---|---|---|
| `display` | Memor banks to Pulsors to lamp rows | `--scene-size n` |
| `framebuffer` | Scrolling frame cache, ring controller | `--scene-size 64/128/256` |
| `wall-pixel` | Per-pixel Catchor decode, Vias, glass | `--scene-size 16 --scene-rows 16` |
| `pattern-wall` | Static 32/64 image, shared drivers, heavy reflood (worst case) | `--pattern circles/checkers --scene-size 32/64` |
| `sawtooth` | Alternating red/blue, split Redirectors, no cross-talk | `--scene-size 32 --scene-rows 16 --pattern circles` |
| `redirector` | Redirector cycling and lane isolation | `--scene-size n` |
| `wire-torture` | Every Trace rule plus a 24x48 field flipping every tick | none |
| `circuits` | Clocks and basic machines | none |
Useful flags: `--tps-unlock --tps 512..8192`, `--no-save`.

## Running headless today
1. **Self-tests (fully headless, no GPU needed):** `./LithoKraft --selftest`. Each scene above has a self-test that builds it, runs N ticks, and checks exact results: pixel colors, no cross-talk, no floating Trace, and **incremental-vs-full-pass equality**. That last check is the correctness gate to copy for the JIT.
2. **Sim timing:** the self-test timing probes report tick cost per scene (used for the 32x32 and 64x64 numbers).
3. **Rendered runs** need a real GPU (Vulkan fails on a headless VM). JD's workstation handles those.

## Known gap to fix first (small)
`--perf-headless` ignores `--bench-scene` and always benchmarks its own built-in world. Make it build the requested scene, then run N ticks with no window, and print avg/p99 tick ms, achieved TPS, and active node counts (optionally as `--bench-json`). That gives you a proper headless profiler for every scene.

## JIT correctness gate (recommended)
For each scene: run the interpreted sim and the JIT sim side by side from the same seed for 2,000+ ticks, and compare every Trace and component state every tick. Any mismatch fails. This is the same pattern as the existing incremental-vs-full test.

## Baselines (JD's laptop, i7 12-thread, RTX 3050 Ti; sim tick avg)
- wall-pixel 16x16: 0.30-0.40 ms at 512 TPS
- pattern-wall 32: 0.12 ms headless / 0.43 ms rendered
- pattern-wall 64: 0.63 ms headless / 1.00-1.08 ms rendered (worst case, the JIT's best target)
- wire-torture: 0.25-0.28 ms at 512 TPS (every Trace flips each tick)
- display scene: holds 8192 TPS at about 0.07 ms
