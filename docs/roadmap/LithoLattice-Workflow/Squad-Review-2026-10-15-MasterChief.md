## Onboarding map (engine layout)
- **Root:** `engine/` is the CMake root (`cmake -S engine`). `game/LithoKraft/` holds the game. engine/LithoKraft is a symlink on Linux, and on Windows the build falls back to the real path. `tools/build.py` is the one-command build. `docs/` holds ARCHITECTURE, ROADMAP, SDK and the briefs. `designers-editors/` and `tools/` hold Python tools (emblem, shield, Systerian translator) and plant_texture_gen.cpp.
- **Engine modules (`engine/src/*`, one static lib each, every module goes to core):** core, procgen, world, sim, render (software, the default), render_vk (Vulkan, which loads the system loader at runtime), ui, assets, texture, subdiv, audio, input, platform (GLFW), script (AngelScript 2.38), mods, console, crypto (Ed25519/SHA-2 mod signing), systerian (certificate codec), index, mcp, defrag, player, entity, ai, anim, camera, sprite, projectile, net, storage.
- **Game (`game/LithoKraft/src`):** content (blocks, model, vegetation), game (lithokraft_game), app (exe and selftests), and headless (a GPU-free harness for CI).
- **Dependencies (FetchContent):** GLFW 3.4, AngelScript 2.38.0, stb_image 2.30, miniaudio 0.11.25, Vulkan-Headers 1.4.363, and glslang 16.6.0. A first configure needs internet. No Vulkan SDK is needed.
- **Tests:** `litholattice_tests <module>` runs 26 engine module tests, plus selftests for camera, systerian, sprite, entity, locomotion, player and projectile. The game side has lithokraft --selftest, screenshot, scout, chipor, fragment, markdown, silica, items, model, authored and agent models, litho_formula gallery and bake, vegetation, and the headless harness, for 48 ctest entries in all. Options are LITHOLATTICE_WERROR, _THREAD_DEBUG, _SANITIZE, _BUILD_TESTS (on), _BUILD_FUZZERS (off), and LITHOKRAFT_DEV_BUILD.
- **Windows Debug recipe:** `cmake -S engine -B build-debug -A x64`, then `cmake --build build-debug --config Debug --parallel`, then `ctest --test-dir build-debug -C Debug -j1 --output-on-failure`.
