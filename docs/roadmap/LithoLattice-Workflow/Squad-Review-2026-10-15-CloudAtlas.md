# Squad Review 2026-10-15: CloudAtlas (assets / texture loading / mod pipeline / path & file security)

Read-only review of `LithoLattice-LithoKraft-Full-Source-2026-10-15` (skipped build*, logs, .orig-*; tree was being edited live, so line numbers are as of ~14:50 ET). Paths are relative to the tree root.

## Top 5
1. **CA-01 Black-box Trace:** GL mipmaps are generated from straight-alpha RGBA, so transparent black texels bleed into lower mips. With the `a < 0.5` cutout, Trace looks dark or boxy at a distance.
2. **CA-02 Registry is missing the new names:** alumitrace, copper_ore and the `*_ore` art are on disk in all 3 packs, but no `resources.json` references them. There's no trace_power LUT asset and no lore_2026-10-15 parts in the tree.
3. **CA-03 Layer cap of 256:** pack_64 already has 195 textures plus animation frames. Adding the 131 lore textures overflows the array, and the overflow silently turns into "missing" checkers.
4. **CA-04 TOCTOU fix bypassed:** `PackStack::find()` returns the unchecked path, and icon loading uses it.
5. **CA-05/06 mod.json hardening:** mod.json is read with no size cap, and mod folders that are symlinks or junctions are accepted. Unsigned mods are never symlink-checked.
