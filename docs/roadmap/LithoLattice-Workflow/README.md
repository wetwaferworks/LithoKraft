# LithoLattice workflow

Working records from building the LithoLattice engine and the LithoKraft game, kept for reference.

- `full-source-snapshot/`: the full source tree as of 2026-10-15. `windows-port-experiments/` inside it holds the Windows-port trials. `hitch-logs/lod-entities/` holds the LOD entity hitch logs from 2026-10-16.
- `pass2/`: the "Pass 2" work package from 2026-10-16.
- `hitch-logs/`: frame-hitch investigation logs.
- `History/` and `credits/`: history notes and credits.

The live code is in `engine/` and `game/` at the repository root. These folders are not part of the build.
