## What is new since the 15:35 package
- **Faster software renderer.** At 1080p borderless with auto threads, walk went from 30.8 to about 45.5 FPS (p99 from 45 to 31 ms), and orbit from 33.3 to about 45 FPS. Two changes did it:
  - **Hierarchical-Z:** 8x8 depth tiles let fully hidden rows of triangles skip without being drawn.
  - **Greedy meshing:** on the software backend only, flat same-texture faces merge into larger quads.
  - The GPU backends still get per-block meshes, so their look is unchanged.
- **16-bit texture layers (CA-03):** the cap goes from 256 to 2048 layers, and the vertex stays 16 bytes. (At 18:00 no blocks were registered; the lithography blocks landed afterwards, see below.)
- **Thread fixes:**
  - The MCP senses tick no longer reads the sim triple buffer from the MCP thread.
  - The registry cache key has an instance id.
  - Audio voice counts get safe accessors.
  - The MCP seams are audited (in Thread-Ownership-Audit, section 6).

## Playing on a CPU-only machine
- Software rendering is the default there. Render threads are set to auto (a power of two up to logical cores minus 2).
- If something looks wrong, these switches help:
  - `LL_MESH_GREEDY=0` turns greedy meshing off for an A/B comparison.
  - `LL_SW_PROF=1` prints per-frame profiling, including Hi-Z rows skipped.
- Determinism hash: `aa82e7afb1eff9d3`, unchanged.
