ROOT CAUSE - PROVEN LIVE-STATE FAILURE
The solid path dropped Pulsor packet semantics: it converted the output into an ordinary attenuating
wire seed, while direct wire received a lossless Pulsor packet. The short one-tick pulse reached the solid
and FIRST adjacent wire immediately, but died/changed strength along the return run; the directly fed
wire/lamp retained it. This is a real propagation mismatch, NOT a CoW-only problem or a late mount pass.
For a strength-1 Pulsor packet, the N7 direct 64-wire route carried 1 throughout, but the solid route's
ordinary seed became 0 after its first wire. A full-strength packet similarly decayed from 64 to 1 over
64 wires instead of retaining 64. This explains why a wire-only path worked but the solid branch did not.

WHY N5/N7 TESTS MISSED IT
Earlier long layouts drove a full-strength packet, then sampled two lamps after the SAME attenuated
return and a Memor. The checks required returnPeak > 0, not equality to the Pulsor's data strength.
The old return peak of 1 therefore passed, and Memor held the sampled value, hiding the transient loss.
N7's asymmetric output paths were downstream of that already-lossy return, so they agreed with each
other without proving direct-packet equivalence across the original solid boundary.
N8 removes the Memor/hold and compares against the component's actual PUBLISHED out, not its animation
state (the raw CellState animation can differ from delayed scheduled output).

ONE FOCUSED PRODUCTION CHANGE
Only signal.cpp changed relative to the N7 production baseline, in the two equivalent seed gatherers:
- cSignalSim::hsPropagateFull
- cSignalSim::hsPrepIncremental
When a pulse-emitting source faces a hard-powered solid, each eligible outgoing Trace face now receives
the existing Pulsor packet record as well as the pre-existing ordinary seed. It runs in THIS SAME tick's
existing flood. The existing packet algorithm carries data strength without decay for its existing
64-wire reach; the pulse disappears on the next tick normally. No pulse widening or new transport delay.
The source-facing back side remains excluded as before; incremental packets require a marked, flat-wire
net, matching direct-wire packet handling. Continuous/non-pulse hard power retains normal attenuation.
No new cache, fullPass_, tick-order rewrite, global scan, engine/render edit, or placement change.
N7's existing hard-neighbor publication and inspector fixes remain; N6 dependency changes remain absent.
Soft still requires custom Alt-scroll connections. Hard power remains colorless. Render culling and mesh
throttles remain render-only and were not changed.
